1 Ejercicio 1: Vectorización y álgebra espacial (Haversine)

La fórmula de Haversine permite calcular la gran distancia sobre la esfera terrestre dadas dos coordenadas en latitud y longitud.

Tu misión es crear una función vectorizada (en Python, R o Julia) llamada calcular_distancias que reciba como argumento el DataFrame df de censos (que construimos en la sección 4) y calcule la distancia en kilómetros desde Bogotá (Lat: 4.7110, Lon: -74.0721) a todas las demás ciudades de la tabla, agregando el resultado en una nueva columna llamada Distancia_Bogota.

  • R
import pandas as pd
import numpy as np

# 1. Datos iniciales
datos_censo = {
    "Ciudad": ["Bogotá", "Medellín", "Cali", "Barranquilla"],

    "Longitud": [-74.0721, -75.5658, -76.5320, -74.7964]
}
# Convertimos el diccionario a DataFrame para aprovechar el procesamiento en bloque
df = pd.DataFrame(datos_censo)
# 1. Datos iniciales (incluyendo coordenadas)

    Ciudad = c("Bogotá", "Medellín", "Cali", "Barranquilla"),
    Latitud = c(4.7110, 6.2476, 3.4516, 10.9639),
    Longitud = c(-74.0721, -75.5658, -76.5320, -74.7964)

# 2. Definición de la función vectorizada
def calcular_distancias(dataframe):
    # Coordenadas de Bogotá (Punto de referencia fijo)
    lat_bog = 4.7110
    lon_bog = -74.0721
    R = 6371.0  # Radio medio de la Tierra en km

    # np.radians es ideal aquí porque procesa toda la columna (Series) a la vez sin ciclos for
    lat1, lon1 = np.radians(lat_bog), np.radians(lon_bog)
    lat2 = np.radians(dataframe['Latitud'])
    lon2 = np.radians(dataframe['Longitud'])

    # Al restar columnas completas, NumPy aplica álgebra lineal optimizada
    dlat = lat2 - lat1
    dlon = lon2 - lon1

    # Aplicamos la fórmula de Haversine usando funciones de NumPy para mantener la vectorización
    a = np.sin(dlat / 2)**2 + np.cos(lat1) * np.cos(lat2) * np.sin(dlon / 2)**2
    c = 2 * np.arcsin(np.sqrt(a))
    
    # Asignamos el resultado a una nueva columna directamente
    dataframe['Distancia_Bogota'] = R * c
    return dataframe
# 2. Definición de la función vectorizada
calcular_distancias <- function(dataframe) {
  lat_bog <- 4.7110
  lon_bog <- -74.0721
  R <- 6371 
  
  # En R, la multiplicación por pi/180 sobre un vector es intrínsecamente vectorizada
  lat1 <- lat_bog * pi / 180
  lon1 <- lon_bog * pi / 180
  lat2 <- dataframe$Latitud * pi / 180
  lon2 <- dataframe$Longitud * pi / 180
  
  # Las diferencias se calculan entre vectores del mismo tamaño
  dlat <- lat2 - lat1
  dlon <- lon2 - lon1
  
  # Usamos las funciones matemáticas base de R que están optimizadas para vectores
  a <- sin(dlat / 2)^2 + cos(lat1) * cos(lat2) * sin(dlon / 2)^2
  c <- 2 * asin(sqrt(a))
  
  # Creamos la columna usando el operador $ para modificar el data.frame original
  dataframe$Distancia_Bogota <- R * c
  
  return(dataframe)
}

Creación: Genera un DataFrame con los siguientes datos de estaciones meteorológicas: Estación: [“Páramo”, “Valle”, “Costa”, “Selva”, “Sabana”] Elevación: [3200, 1500, 15, 200, 2600] Precipitación: [850.5, 1200.0, None, 3000.5, None] (Usa el tipo de nulo apropiado según tu lenguaje: None/np.nan, NA o missing).

import pandas as pd
import numpy as np

# 1. Creación con nulos (NaN): Usamos np.nan porque Pandas lo reconoce como nulo numérico
datos = {
    "Estacion": ["Páramo", "Valle", "Costa", "Selva", "Sabana"],
    "Elevacion": [3200, 1500, 15, 200, 2600],
    "Precipitacion": [850.5, 1200.0, np.nan, 3000.5, np.nan]
}
df = pd.DataFrame(datos)
# 1. Creación con nulos (NA): NA es el valor lógico estándar de R para datos faltantes
df <- data.frame(
  Estacion = c("Páramo", "Valle", "Costa", "Selva", "Sabana"),
  Elevacion = c(3200, 1500, 15, 200, 2600),
  Precipitacion = c(850.5, 1200.0, NA, 3000.5, NA),
  stringsAsFactors = FALSE
)
  1. Imputación: Los sensores de la Costa y la Sabana fallaron. Rellena los datos de precipitación nulos utilizando el valor promedio (media) de las estaciones válidas.
  • python
  • R
# 2. Imputación: Usamos .mean() porque ignora automáticamente los nulos para el cálculo
media_precip = df["Precipitacion"].mean() 

# .fillna() es la función estándar de Pandas para reemplazar nulos sin borrar filas completas
df["Precipitacion"] = df["Precipitacion"].fillna(media_precip)
# 2. Imputación
# 2. Imputación: Usamos na.rm = TRUE para que R no devuelva NA como resultado del promedio
media_precip <- mean(df$Precipitacion, na.rm = TRUE)

# is.na() es la función correcta para indexar celdas vacías y asignarles un nuevo valor
df$Precipitacion[is.na(df$Precipitacion)] <- media_precip
  • La Imputación (Manejo de Nulos) Rellenar con la media es una técnica de Imputación Simple. Es vital porque la mayoría de los algoritmos de Machine Learning o modelos espaciales fallan si encuentran un valor NaN/NA.

En Python: fillna() es un método muy potente que permite incluso rellenar con el valor anterior o siguiente.

En R: is.na() es un filtro lógico que identifica las celdas vacías para poder actuar sobre ellas.

  1. Filtro espacial (Slicing): Extrae en un nuevo DataFrame llamado estaciones_altas solo aquellas filas cuya elevación sea estrictamente mayor a 1000 metros.

# 3. Filtro espacial: Slicing por condición
# Usamos una máscara booleana (df["Elevacion"] > 1000)
# .copy() asegura que 'estaciones_altas' sea un nuevo objeto y no una vista del anterior
estaciones_altas = df[df["Elevacion"] > 1000].copy()
# 3. Filtro: Usamos el sistema de coordenadas [filas, columnas] de R
# La condición df$Elevacion > 1000 selecciona solo las filas que cumplen la regla
estaciones_altas <- df[df$Elevacion > 1000, ]
  • Slicing y Filtrado Al filtrar por Elevacion > 1000, estamos reduciendo el “universo” de nuestro análisis.

Importante: En Python, usamos .copy() al crear estaciones_altas. Esto evita el famoso SettingWithCopyWarning, asegurando que el nuevo DataFrame sea independiente del original en la memoria.
